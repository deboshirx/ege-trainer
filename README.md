# Тренажёр ЕГЭ

Telegram Mini App для подготовки к ЕГЭ: профильная и базовая математика, русский язык, обществознание, история, биология, химия, физика, литература.

- `index.html`, `app.js` — приложение
- `subjects/*.js` — задания по предметам (один файл на предмет)
- `curators.js` — список кураторов (имя, ник в Telegram, предметы)
- `bot/worker.js` — бот для Cloudflare Workers (ответ на /start кнопкой мини-аппа)
- `tools/validate.js` — проверка данных: `node tools/validate.js`

## Рисунки, формулы и таблицы

- Формулы в тексте задания пишутся в `$...$` (LaTeX, KaTeX лежит в `vendor/katex`).
- Рисунок задаётся полем `fig` у задания (графики функций, диаграммы, чертежи) — формат описан в начале `figures.js`. Строка `{fig}` в тексте ставит рисунок в нужное место, иначе он идёт после условия.
- Задания с рисунками и подписи к существующим добавляются в `pictures.js`.
- Таблица соответствия строится автоматически из строк `А) … Б) …` и `1) … 2) …`; заголовки столбцов — строкой капсом перед блоком или полем `cols: ['Левый', 'Правый']`.
